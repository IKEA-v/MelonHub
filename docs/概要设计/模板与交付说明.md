## 3 重建

建模工具使用 PlantUML 1.2025.0 绘制 UML，Graphviz（`@viz-js/viz`）绘制 DFD；DOT 内容保存在 PlantUML `@startdot` 源文件中，可直接提取。模型全部本地渲染。PDF 使用 Python ReportLab，中文字体默认读取 Windows 黑体，可通过 `MELONHUB_PDF_FONT` / `MELONHUB_PDF_BOLD_FONT` 指定替代字体。

运行前准备 Java、PlantUML jar、Node.js、`@viz-js/viz`、`@resvg/resvg-js`，以及 Python 的 reportlab、Pillow。项目既有图工具可由 `.local/er-tools/package.json` 提供 Node 依赖；也可用 `MELONHUB_DIAGRAM_NODE_MODULES` 指向自己的依赖解析入口。jar 默认从忽略的 `.local/design-tools/plantuml.jar` 读取，可用 `PLANTUML_JAR` 指定。

```powershell
node docs/概要设计/render-figures.cjs
python docs/概要设计/build-pdf.py
```

PDF 正文为 A4 纵向，宽图独立横向页；第一层 DFD 单独使用 A3 纵向图页以保留全部数据流标注。PDF 含目录、书签、页码和附录 B。验收中间图片置于忽略的 `tmp/pdfs/outline-design/`，不作为提交材料。
