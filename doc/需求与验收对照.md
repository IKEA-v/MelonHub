# MelonHub 需求与验收对照

本表以 MelonHub 的权限平台功能和第二轮验收为范围。课程管理平台用于验证外部软件接入。现有测试文件可直接定位现行代码路径，在线复验结果按本轮证据记录。

| 编号 | MelonHub 要求 | 自动化依据 | 云端验收行为 |
| --- | --- | --- | --- |
| MH-01 | 管理员登录、会话、两步验证与凭据失效 | [SecurityIntegrationTest](../backend/src/test/java/com/melonhub/rbac/SecurityIntegrationTest.java) | 用验收账号登录，确认账号菜单和角色，退出后再次访问 |
| MH-02 | 平台管理员按功能、部门和软件分级 | [AdminRoleIntegrationTest](../backend/src/test/java/com/melonhub/rbac/AdminRoleIntegrationTest.java)、[AdminTreeIntegrationTest](../backend/src/test/java/com/melonhub/rbac/AdminTreeIntegrationTest.java) | 比较超级管理员、课程授权管理员和审计员的菜单及按钮 |
| MH-03 | 部门 × 软件隔离、角色和权限分配、部门切换 | [RbacIntegrationTest](../backend/src/test/java/com/melonhub/rbac/RbacIntegrationTest.java)、[PermissionCacheIntegrationTest](../backend/src/test/java/com/melonhub/rbac/PermissionCacheIntegrationTest.java) | 选择正确授权域，核对成员角色与权限诊断 |
| MH-04 | 分配有效期、审批、复核与审计 | [GovernanceIntegrationTest](../backend/src/test/java/com/melonhub/rbac/GovernanceIntegrationTest.java) | 打开审批、复核和审计，核对变更状态及记录 |
| MH-05 | 两个系统在 Swarm 运行，课程身份和权限由 MelonHub 提供 | [IdentityTokenServiceTest](../backend/src/test/java/com/melonhub/rbac/identity/IdentityTokenServiceTest.java)、[统一身份 OpenAPI](identity-openapi.yaml) | 逐一核对四服务副本，用课程验收账号验证登录及权限结果 |
| MH-06 | 菜单请求在后端 Logback 可以按请求编号定位 | [ApiGuardRequestLogTest](../backend/src/test/java/com/melonhub/rbac/security/ApiGuardRequestLogTest.java) | 切换「用户」「系统状态」「审计日志」，用响应头 `X-Request-Id` 对照后端日志 |
| MH-07 | 控制台前端身份与会话更新正常 | [api.test.mjs](../frontend/tests/api.test.mjs)、[浏览器验证记录](验证记录.md#7-控制台浏览器检查) | 打开控制台、登录、切换菜单、退出并确认未登录限制 |
| MH-08 | HTTP 响应契约可供调用方核对 | [ApiContractTest](../backend/src/test/java/com/melonhub/rbac/ApiContractTest.java)、[API 文档](API.md) | 选一个成功请求和一个错误请求，核对 HTTP 状态、响应字段与请求编号 |
